# 大学生反诈宣传游戏项目

面向大学生的反诈宣传互动网页游戏项目（课程 / 实践项目）。

## 当前内容

以古代战局为背景的卡牌抉择游戏「古代战局 · 王权」：玩家在有限的回合内管理
**兵力 / 粮食 / 民心 / 国库** 四项国力，通过每一次抉择推进战局。

## 目录结构

| 文件 | 说明 |
| --- | --- |
| `ancient-war-card-single.html` | 单文件版，双击即可在浏览器运行 |
| `app.js` | 游戏核心逻辑（国力状态、事件、存档） |
| `style.css` | 界面样式 |
| `.gitattributes` | 换行符统一为 LF |

## 运行方式

直接双击 `ancient-war-card-single.html`，或用任意静态服务器打开仓库根目录。

## 环境

纯前端、零依赖、离线可运行（HTML + CSS + 原生 JavaScript）。
